# 🏭 FactoryIO Development Project (TwinCAT 3)

This repository contains my ongoing development project for FactoryIO using TwinCAT 3.

The goal is to build reusable function blocks and HMI user controls for controlling different components and processes in FactoryIO scenes.

⚠️ This project is still work in progress.

---

## 🚀 Functionality

- Development of reusable PLC function blocks
- HMI user controls for visualization for interaction via a HMI
- Creation of a TwinCAT 3 library

---

## 🧱 Project Structure

- `FunctionBlocks/` → PLC logic for FactoryIO components  
- `HMI/` → User controls and UI elements  
- `Library/` → Compiled function blocks for reuse  

---

## 🔧 Technologies

- TwinCAT 3  
- PLC (Structured Text)
- HMI TE2000
- Factory I/O   

---

## 📌 Status

This project is currently under active development and will be extended continuously.
